## Not confirmed from source

The verifier could not settle these either way:

- Mod+wheel zoom on macOS trackpad pinch: Electron gets pinch through 'zoom-changed'; native handles only ScrollEvent with the secondary modifier (zoom.rs:262). Whether GPUI delivers a macOS magnify gesture as such an event is in the external gpui-kit crate, not in this checkout.
- Windows taskbar grouping: whether gpui-kit's WindowOptions.app_id sets a Windows AppUserModelID is decided in the external crate; only the id value and the embedded icon were confirmed here.
- Frameless window controls: minimize/maximize/close and the drag region come from gpui-kit's TitleBar component (title_bar.rs:165); its behaviour is in the external crate and no native test or smoke assertion for those three buttons was found.
- Edit menu items: native dispatches gpui_kit::base::input actions (Undo/Redo/Cut/Copy/Paste/SelectAll); that they act on the focused field is implemented in the external crate. No test found for the in-window Edit menu.
- copilot.premiumModel: native stores and edits the value; whether native PR actions consume it the way Electron's PullRequestHistoryPanel does belongs to the GitHub/Copilot area and was not checked.
- Sidebar count badges: native ring rendering and the GitHub badge source were read, but no test or smoke scene exercising the ring was found.
- Smoke-script evidence (scripts/native-smoke/\*.py) was read, not run; rows cite what the scripts assert, not a passing result.
- Settings > Copilot account and Settings > Notifications toggle: the mapper cited settings-desktop.py 'preferences' assertions for these; the lines read show the drive visiting those panels but I could not confirm a specific assertion for the account field or the toggle label, so that evidence was removed rather than confirmed.
- Dashboard uptime badge: the formula matches, but when Convex still holds a lastSessionStart from an Electron session that never recorded its end, the native badge counts from that timestamp; this follows from the missing session-stat writes and was reasoned from convex/buddyStats.ts, not observed.
